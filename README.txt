DUAL SWITCH — PWA

Номера телефонов не встроены в исходный код. Введите их в приложении на каждом iPhone; они сохраняются только в локальном хранилище этого браузера.

Файлы: index.html, manifest.json, sw.js, icon-192.png, icon-512.png.

Важно: iOS не позволяет веб-приложению выполнять USSD без подтверждения пользователя. Кнопка открывает системный набор номера; пользователь должен подтвердить вызов и дождаться ответа оператора.

При смене телефона отключите переадресацию на телефоне, который берёте с собой, затем включите её на оставляемом телефоне. Проверьте, что услуга включилась у оператора.
