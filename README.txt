DUAL SWITCH — первая версия PWA

Файлы:
- index.html — приложение
- manifest.json — настройки установки
- sw.js — офлайн-кэш
- icon-192.png / icon-512.png — иконки

Публикация:
1. Загрузить все файлы в корень HTTPS-хостинга (например, GitHub Pages или Netlify).
2. Открыть опубликованный HTTPS-адрес в Safari на каждом iPhone.
3. Нажать «Поделиться» → «На экран Домой».
4. На каждом телефоне выбрать установленного оператора в списке.

Важно:
- iOS не позволяет PWA отправлять USSD-команды без подтверждения пользователя.
- Кнопка открывает системный набор номера; пользователь должен нажать вызов.
- После команды дождитесь ответа оператора.
- Для смены направления отключите старую переадресацию на телефоне, который берёте с собой, затем включите переадресацию на оставляемом телефоне. Иначе возможна петля.
- ##21# отключает безусловную переадресацию (код 21), а не все виды переадресации.
